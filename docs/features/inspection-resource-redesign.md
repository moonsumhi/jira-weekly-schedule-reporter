# 자원 점검 화면 재설계

## 목적

사용자는 매월 기존 Excel을 가져온 뒤, 어디에 이상이 있고 어떤 서버 결과가 빠졌는지 확인하고 서버별 상세 점검·조치 내역을 검토한다. 정기 대상을 설정하는 일은 반복적인 결과 검토와 분리한다.

## 화면 구성

- 자원 점검 안에서 `점검 결과`와 `월별 비교`를 전환한다. 월과 점검 기록 선택은 두 보기에서 공유하며, 기존 현황/자료 구분은 사용하지 않는다.
- 상단 작업: 기존 `Excel 업로드`와 `정기 대상 설정`. 정기 대상은 기존 등록 자산 선택 대화상자에서 관리한다.
- 확인할 항목: 측정 결과(건), 확인 필요(건), 결과 없는 정기 대상(대), 자산 미연결(건). 카드를 누르면 해당 항목만 표시하며 다시 누르거나 필터 초기화로 전체를 본다. 카드 선택 시 이전 검색어는 지운다.
- 결과 목록: 모든 측정 행과 연결된 결과가 없는 정기 대상을 합쳐 표시한다. 위험·주의·수치 누락 등 확인 항목을 먼저 정렬하고, CPU·RAM·디스크 최대값과 전월 대비 변화, 로그·조치·점검 이상 항목을 함께 표시한다.
- 결과가 없는 대상은 측정치 0 또는 정상으로 표시하지 않는다. 파일 자체가 없는 월은 등록 대기로 표시한다. 같은 자산에 여러 측정 행이 연결되어도 개별 결과를 보존한다.
- 서버명은 연결된 자산으로 이동한다. `상세`는 기존 점검 상세·조치·추이 대화상자를 연다. 미연결 또는 예외 연결 행의 `자산 연결/연결 변경`은 해당 행의 연결 대화상자를 연다. 자동 호스트명 일치와 이번 자료에만 적용하는 예외 연결 정책은 유지한다.
- 모바일에서는 가로로 긴 표 대신 서버별 카드로 상태·측정값·확인할 내용·상세 진입을 제공한다.
- 월별 비교는 선택한 점검 기록과 전월의 최신 자료를 기본으로 비교한다. 같은 달의 직전 업로드를 전월로 간주하지 않는다. 비교 기준 자료를 직접 바꿀 수 있고 검색·정렬·서버별 상세·추이 조회를 유지한다. 기존 비교 지표인 CPU·RAM·Disk Total을 사용하며 증감은 %p로 표기한다. 모바일에서는 서버별 이전→현재 카드로 표시한다.
- 비교 자료가 없는 경우 현재 측정값만 보여주고 비교 기준을 선택하도록 안내한다. 조회 실패 시 이전 결과를 새 비교 결과처럼 표시하지 않으며 재시도를 제공한다.
- 서버 점검 메뉴에서는 월별 비교 항목을 제거한다. 기존 `/inspection/health-compare` 링크는 월·자료 쿼리를 유지하며 `/inspection/health-servers?tab=compare`로 연결한다. 서버 시작 시 기존 메뉴도 중복 없이 정리한다.

## 서버별 상세 팝업

- `자원 사용량`, `점검 항목`, `조치 내역` 탭으로 내용을 나누며, 서버 이름·IP·OS와 탭은 스크롤 중에도 보인다. 점검자와 점검·종료·재기동 시간은 별도 영역에 표시한다.
- CPU·RAM·디스크 최대 사용률은 큰 숫자, 상태 표시, 사용량 막대로 보여준다. 디스크별 사용/전체 용량과 사용률을 함께 표시하고, 모바일에서는 읽기 쉬운 행으로 재배치한다. 0%와 측정값 누락은 구분한다.
- 하드웨어 점검은 항목과 결과를 나란히 표시한다. 보안 결과와 서비스 상태는 원문을 보존하며, 모든 서비스를 정상으로 표시하지 않는다.
- 점검표에 적힌 로그·조치 사항·종합 의견과 직접 등록한 조치 내역을 구분한다. 수정·삭제 버튼, 증빙 이미지 확대, 조치 상태를 명확히 표시하며 탭 전환 중에도 작성 중인 조치 내용을 유지한다.
- 조치 및 사용량 추이 조회가 실패하면 조회 실패와 재시도 버튼을 표시한다. 조회 실패를 조치 미등록이나 측정 기록 없음으로 표시하지 않는다.

## 유지하는 입력 계약

Excel 파일 형식, `.xlsx` 선택, FormData의 `file`, POST `/health-reports`, 같은 점검일 재업로드 처리, 파서, 저장 구조, 업로드 후 해당 월/자료 선택은 변경하지 않는다. 업로드·삭제·정기 대상·예외 연결 API도 기존 것을 사용한다. 백엔드 계산과 월간 보고서 생성 기능은 그대로 둔다.

조회와 재시도는 입력 작업을 대신 실행하지 않는다. 월·업로드 기록 변경 시 검색과 필터를 초기화한다. 외부 읽기 전용 사용자에게는 업로드·삭제·대상 변경 입력을 표시하지 않는다.
