# 월간 서버 점검 계획서·결과서

월간 작업에서 점검 전 제출하는 계획서와 점검 후 제출하는 결과서를 각각 작성한다. 같은 월에도 두 문서를 별도로 저장하며, 기존 점검 보고서는 결과서로 취급한다. Excel import 형식과 Node 의존성은 변경하지 않는다.

## 작성 흐름

- 월간 작업의 `점검 계획서`, `점검 결과서` 버튼은 선택한 월의 최신 문서를 연다. 문서가 없으면 초안 생성 화면을 연다. 검색어, 담당자, 자산 필터는 문서 범위에 적용하지 않는다.
- 목록 화면에서 계획서·결과서 탭과 월을 바꿀 수 있다. 서버 점검의 `계획서·결과서` 메뉴에서도 접근한다.
- 작성한 초안을 확정하면 해당 내용은 보존된다. 수정할 때는 개정본을 작성하며, 이전 확정본도 조회·출력할 수 있다.
- 서버 점검 권한과 기존 내부망 쓰기 제한을 그대로 적용한다. 각 문서는 인쇄 또는 PDF 저장이 가능하다.

## 계획서

- 측정 자료가 없어도 정기 자원 점검 대상과 해당 월에 진행할 작업으로 작성할 수 있다. 자원 자료의 누락·완료율·수행 결과를 계획서에 표시하지 않는다.
- 자원 점검 대상은 `inspection_resource_targets`에 등록된 자산으로 구성한다. 월간 작업의 대상 자산와 구분해서 표시한다.
- 해당 월의 `ACTIVE` 작업을 포함하며, 이슈와 작업계획서에서 직접 등록한 작업 모두 지원한다. 이미 이월·제외된 회차와 이전 달의 미완료 작업은 포함하지 않는다.
- 각 작업에는 작업명, 대상 자산, 담당자, 예정일과 연결된 개별 작업계획서를 표시한다. 작업별 일정이 없으면 문서의 점검 예정일을 사용한다.
- 최초 초안에는 월간 작업 담당자로 등록된 이용 가능한 백오피스 사용자를 참여 예정자로 채운다. 역할과 수기 담당 업무는 참여자 관리에서 수정한다. 새로고침은 기존 참여자 선택을 유지하고 담당 작업 연결만 갱신한다.
- 예정 시간, 자원 점검 항목, 점검 목적, 사전 준비 및 유의사항을 수정할 수 있다. 추가 안내는 항목별 추가·수정·삭제를 지원한다.
- 초안에서 최신 내용을 불러오면 대상 서버와 작업을 갱신하며, 직접 쓴 점검 항목·시간·준비 사항은 유지한다. 계획서에서는 결과·조치 저장 API를 사용할 수 없다.

## 결과서와 계획 연결

- 결과서 초안의 자료를 불러올 때 같은 월의 가장 최근 확정 계획서를 함께 저장한다. 초안 상태인 계획서는 기준으로 사용하지 않는다.
- 연결 정보에는 확정 계획서 ID·차수·예정일, 당시 대상 서버와 작업·참여자 등이 들어간다. 계획서나 이슈를 나중에 변경해도 결과서에 연결된 계획은 바뀌지 않는다.
- 결과서 새로고침과 개정본 작성은 이미 연결된 계획서 차수를 유지한다. 연결 계획서가 없는 기존 초안은 최신 내용 불러오기 시 확정 계획서가 있으면 연결한다. 확정된 기존 결과서는 변경하지 않는다.
- 계획서에 있던 참여자·역할은 결과서 초안에 가져오되, 계획서의 수기 담당 업무를 실제 수행 결과로 복사하지 않는다.
- `계획 대비 수행 현황`에는 계획 작업 수, 계획 중 완료한 작업 수, 미완료·미실시·이월 수, 추가 작업 수를 표시한다. 작업명·담당자·대상 자산·일정의 변경은 당시 계획과 현재 내용을 함께 표시한다.
- 작업은 회차의 월과 작업 ID로 대응한다. 자산명 변경이나 대상 자산 순서 변경은 계획 변경으로 집계하지 않는다. 결과서에서 사라졌거나 제외한 계획 작업은 미실시, 다른 달로 넘긴 작업은 이월로 표시한다. 계획에 없던 작업은 추가 작업으로 표시하되 제외된 작업은 추가 건수에서 뺀다.
- 계획서가 없는 과거 월은 기존과 같이 결과서만 작성·출력할 수 있다.

## 호환성과 저장

`monthly_inspection_reports`와 기존 확정·개정·동시 편집 보호 로직을 공유한다. 새 문서는 `kind=PLAN|RESULT`를 저장하며, 종류가 없는 기존 문서는 `RESULT`로 읽는다. 계획서의 범위 키에 `plan:` 접두사를 사용해 기존 결과서의 고유 인덱스와 충돌하지 않으며 기존 문서를 일괄 변경하지 않는다.

검증: 측정 자료 없는 계획서, 대상 서버 구분, 이슈·작업계획서 포함 범위, 계획서·기존 결과서의 공존, 참여자 자동 연결, 확정본 보존, 계획 개정 후 결과서 기준 유지, 종류 변경·결과 쓰기 차단, 동시 수정 및 권한, 계획 대비 변경 집계, PC·모바일 표시, 인쇄/PDF.

## 월간 작업의 대상 자산

- 점검 작업을 추가하거나 수정할 때 서버·네트워크·정보보호시스템·DBMS·VMware·랙을 모두 선택할 수 있다. 유형 필터와 자산명·관리번호·IP 검색을 제공한다.
- 저장한 자산의 유형을 보존하고 해당 유형의 자산 화면으로 연결한다. 서버 외 자산 상세에서도 운영 이력을 조회할 수 있다.
- 정기 자원 점검 대상과 측정 자료의 자산 연결은 서버로 한정한다. 결과서에서 서버 외 작업 대상은 측정 자료 누락으로 집계하지 않는다.
